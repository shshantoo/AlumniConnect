# Taste Skill — The Anti-Slop Frontend Framework

Reference URL: [Taste Skill](https://www.tasteskill.dev) | Repository: [github.com/Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)

## Core Design Principles
1. **Anti-Slop Visual Quality**: Avoid generic, plain red/blue/green components, default browser controls, or unstyled flat rectangles.
2. **Signature Color Tokens**:
   - Primary Accent: Electric Orange (`#ff5500` / `#e04b00`)
   - Neutral Warm Canvas: `#f8f6f0`
   - Dark Canvas / Text: `#0a0a0a` / `#18181b`
   - Border Subtle: `#e5e0d5` / `zinc-200`
3. **Tactile Micro-Interactions**:
   - `hover:scale-105 transition-all duration-300`
   - Subtle shadow elevation (`shadow-md shadow-orange-500/25`)
   - Active press scale (`active:scale-[0.98]`)
4. **Responsive Layout Grid & Spatial Typography**:
   - Fluid container padding across mobile (`px-4`), tablet (`px-6`), and desktop (`px-8`).
   - Clean heading hierarchy (`h1`, `h2`, `h3`, `h4`) with tight tracking and custom pill badges.
